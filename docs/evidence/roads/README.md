# Дороги: визуальная проверка 3D и карты

Набор снят из **реально запущенного проекта**, а не нарисован отдельно: 3D — Three.js/WebGL, карта — рабочий Canvas-рендер `FullMap`. Дорожная геометрия на исходных кадрах не изменялась. Монтажи только уменьшают кадры и добавляют подписи.

## Быстрый просмотр

- `00-3d-map-comparison.jpg` — четыре пары «3D сверху / карта» с одинаковыми мировыми координатами и сопоставимым масштабом.
- `01-opposite-angles.jpg` — те же локации в 3D с юго-востока и северо-запада.
- `index.html` — галерея монтажей и всех исходных кадров.
- Исходники: 16 файлов JPG, 1440 × 900; для каждой локации два ракурса, вид сверху и карта.

`manifest.json` содержит координаты, параметры карты и результат сбора ошибок браузера. В финальном прогоне ошибок страницы и консоли нет.

## Что подтверждается дополнительно

Визуальная выборка не заменяет полный автоматический контроль:

- 5 157 узлов, 7 097 исходных рёбер и 28 запланированных развязок;
- LOD0 карты двусторонне согласован с дорожным графом: все центральные линии найдены в допуске 1,5 м, неподтверждённых обычных дорожных штрихов в допуске 2,1 м нет;
- все 28 развязок имеют верхний уровень на карте;
- `roadlevels`: 28 пересечений, минимальный просвет 5,794677 м, ошибок нет;
- `roadprobe`: 2 548 418 проб, `highwayLaneGaps=0`;
- `roadsteps`: 3 219 223 образца, `over10cm=0`.

Проверки: `npm run check:roads`, `npm run check`, `npm run build`.

## Повторная съёмка

При работающем dev-server на порту 5317:

```sh
npm install --no-save --package-lock=false playwright @sparticuz/chromium
node tools/road_evidence.mjs
python tools/evidence_sheets.py
```

`EVIDENCE_SITES=04-downtown` переснимает только одну локацию. `LEONIDA_URL` позволяет задать другой адрес сервера. В минимальном Linux-контейнере Chromium может требовать системные библиотеки из `al2023.tar.br`, поставляемого `@sparticuz/chromium`.

Эти зависимости нужны только для документирования и не добавляются в production bundle или manifest проекта.
